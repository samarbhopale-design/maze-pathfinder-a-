📘 Python Lab Practical: A* Search Algorithm

1. Aim

To implement the A* (A-Star) Heuristic Search Algorithm in Python to find the shortest path from a starting cell (S) to a goal cell (G) in a 2D maze with obstacle walls (1).

2. Theory of A* Heuristic Search

A* is an informed search algorithm combining Dijkstra's algorithm and Greedy Best-First search. It evaluates nodes using:

f(n) = g(n) + h(n)
  • g(n): Exact movement cost from Start to node n.
  • h(n): Heuristic estimated cost from node n to Goal.
  • Manhattan Distance: h(n) = |x1 - x2| + |y1 - y2| (ideal for 4-directional grids).

3. Algorithm Steps

  1. Initialize open_list with Start node, g(Start) = 0, and f(Start) = h(Start).
  2. While open_list is not empty, pop the node with the lowest f(n).
  3. If the current node is Goal, reconstruct and return the shortest path.
  4. Otherwise, add current node to closed_set and explore all 4 adjacent neighbors (Up, Down, Left, Right).
  5. For each non-wall neighbor not in closed_set, calculate tentative_g = g(current) + 1.
  6. If tentative_g < g(neighbor), record parent pointer, update g and f scores, and insert into open_list.
  7. If open_list empties without reaching Goal, return "No path found".

4. Conclusion

The A* algorithm guarantees the optimal (shortest) path when using an admissible heuristic like Manhattan Distance, efficiently pruning unpromising branches compared to uninformed search techniques.
